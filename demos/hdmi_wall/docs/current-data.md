# 视频墙性能与验证入口

[HDMI 用法](../README.md) · [性能指标解释](../../../docs/performance-overview.md)

当前采用线性解码输出＋8 块额外缓冲。按用途选择配置；各报告独立保留输入、设备链路、时长和计数范围，不跨报告拼接成绩。

| 用途 | 配置与结果 | 适用范围 |
|---|---|---|
| 看画面，选择每卡路数 | [五档布局与实测](layouts.md) | 三卡并发、每档 45 秒，预览不限频；4 / 8 路接近素材 24 FPS，32 路每路约 7.5–8.7 FPS |
| 复现高路数吞吐测量 | [三卡各 32 路测试](three-card.md) | 三卡每卡 300 秒、预览上限 3 FPS；含年龄淘汰，不是流畅度验收 |
| 查线性方案接入与不同素材结果 | [线性解码与素材验证](linear-materials.md) | 09-28 双卡短测；官方 24p 与 highway 25p 分开记录 |
| 查为什么 PCIe2 性能得到改善 | [VPP 根因报告](../../../docs/vpp-root-cause.md) | 隐藏布局展开、共享资源等待与格式 / 缓冲对照 |
| 追溯历史测试 | [历史报告索引](../../../docs/archive/README.md) | 各阶段按原条件保存，不代表当前默认配置 |

32 路支持多路检测展示，当前 YOLOv8s 与检测后更新预览的流程达不到每路 24 FPS。预览提交率不等于屏幕刷新率；TPU 高利用率不等于每路流畅或全帧检测。四卡能力和四小时稳定性尚未完成本轮硬件验证。

所有详细数字集中在对应报告及其 JSON 摘要，入口页不再重复维护整套历史表。
