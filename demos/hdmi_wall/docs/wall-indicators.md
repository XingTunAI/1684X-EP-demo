# 32 路视频墙指标说明

[仓库首页](../../../README.md) / [HDMI 文档导航](../README.md#文档导航) / [实测索引](results.md)

这些是屏幕上的观测指标，运行命令中的 `--streams`、`--infer-fps` 等属于配置参数。普通视频墙保留全部 32 个视频格；多设备同时运行，通过顶部按钮切换页面。

## 顶部汇总

| 指标 | 含义与读法 |
|---|---|
| `DEVICE 0 / 1` | 模组设备编号；每页对应一张卡，切页不会暂停其他卡。编号与 PCIe 规格的对应关系需要以本次实际识别为准。 |
| `PCIE 2.0 X1 / 3.0 X2` | 实际协商的 PCIe 代际和通道数，描述主机与模组之间的连接。它不是视频帧率。 |
| `32 CH`、`CH 01…32` | 本卡配置的通道数、格子的通道编号。当前测试可以由多个独立解码器读取同一份本地视频。 |
| `TPU 100%` | 最近一次设备计算利用率采样；不能据此判断解码是否满帧。没有有效采样或采样过期时为 `--`。 |
| `TOTAL DEC` | 本卡所有通道实际成功解码 FPS 之和，在应用抽帧之前计数。 |
| `TARGET` | 已知本地输入帧率之和。当前素材为 24 FPS，32 路目标为 **768 FPS**；32 路 25 FPS 才是 800。未知输入目标显示 `--`。 |
| `TOTAL INF` | 本卡所有通道实际检测完成 FPS 之和，计数点为 Detect 成功返回。 |
| `Rolling 2s` | DEC / INF 使用最近 20 个完整的 100 ms 时间桶统计；是近期速度，不是整场平均，短时波动或补帧可使读数略高于 TARGET。 |
| `HDMI cap 10 FPS` | 整幅视频墙的预览刷新上限，实际刷新可能更低；不是每路输出独立的 1080p 视频，也不是显示器物理刷新率。 |
| `VIEW LIVE` | 播放器最近收到该设备的视频墙画面，不表示每个通道都没有停顿或延时。 |
| `VIEW UPDATE` | 距该页最近一次画面更新的时间；不是源视频到显示器的端到端延时。 |
| `Policy latest` | 优先处理最新解码帧，主动舍弃被覆盖或送检前超龄的帧。不是固定每 N 帧取一帧。 |
| `yolov8s_int8_1b.bmodel` | 当前检测模型：YOLOv8s、INT8、batch 1。 |

## 每路速率与时间

| 指标 | 含义与读法 |
|---|---|
| `DEC 24.0` | 该路最近每秒成功解码约 24 帧。与输入帧率比较，可观察是否跟上输入。 |
| `INF 8.0` | 该路最近每秒完成约 8 帧检测。DEC 24、INF 8 表示解码和送检的速度不同，不是只解码了 8 帧。 |
| `LAG 40ms` | 最近成功解码的帧，在解码完成时比本地源计划时刻晚 40 ms，负值截为 0。包含取帧和调度等影响，不等于纯硬件解码耗时；直播源无此本地时间基准时为 `--`。 |
| `AGE 15ms` | 距该路最近一次成功解码已经过 15 ms。没有新解码帧时会持续增加，用于发现停顿。 |
| `src age 220ms` | 当前显示的检测帧，从本地源计划时刻到视频墙渲染时已经过 220 ms，包含处理与旧画面停留时间。 |
| `dec age` | 无本地源时间基准时，当前显示的检测帧从解码完成到渲染的年龄；未涵盖相机、网络和解码器内部先前缓存。 |
| `drop 90` | 该检测画面携带的累计应用主动丢帧数，包括 latest 覆盖、超龄丢弃和收尾丢弃；不是网络丢包或解码错误数。 |

例如 `DEC 24 / INF 8 / LAG 40ms / AGE 15ms / src age 220ms`：解码约 24 帧/秒，检测约 8 帧/秒；最新解码帧完成时落后计划 40 ms，距那次完成已有 15 ms；正在显示的检测结果对应更早的一帧，其源年龄为 220 ms。

**LAG、AGE、src age 不能直接相加**：它们的时间起点、终点和对应帧不同。上述年龄都不能替代相机到 HDMI 屏幕的实际端到端测量，渲染之后的播放器传输和屏幕扫描也未计入。

## 状态提示

| 状态 | 当前触发条件 |
|---|---|
| `START` | 观测时钟尚未启动或启动不足 2 秒，等待统计稳定。 |
| `OK` | 当前未触发下面的解码降速或停顿条件；不代表性能全面验收通过。 |
| `SLOW` | 启动窗口结束后，解码 FPS 连续 3 秒低于已知目标的 85%。24 FPS 输入对应低于 20.4 FPS。 |
| `STALL` | 启动窗口结束后仍没有成功解码，或距上次成功解码超过 2 秒。 |
| `STALE` | 当前显示的检测结果年龄超过 2 秒；本地使用 src age，直播使用 dec age。解码仍在运行时，检测画面也可能 STALE。 |

主管关注的“推理满载时解码下降多少”，需要在相同输入和通道数下比较纯解码与带推理的 DEC，同时看 TPU、LAG 和停顿。仅看 INF、TPU 或画面仍在动，无法得出这个结论。详细对照入口见 [解码观测](decoder-observation.md)。
