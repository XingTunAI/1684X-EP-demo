# 单卡视频分析 Demo：演示说明与当前进度

更新日期：2026-09-07。本阶段以演示和性能测量为目标，现有测试已完成，暂不追加客户素材测试或抽帧开发。

## 演示结论

当前 Demo 已跑通单卡硬件解码、图像预处理、YOLOv8 推理、检测后处理和结构化结果输出。32 路同时分析时，优化后总吞吐为 **114.10 FPS**，平均每路 **3.57 FPS**，相同条件下比原图像路径提升约 **3.49 倍**。

这是当前模型、素材和程序实现的实测值，不代表芯片极限。默认只记录性能，不以每路 25 FPS 判通过或失败；进程异常、停帧和结果不完整仍会记录为错误。

## 固定演示配置

| 项目 | 配置 |
|---|---|
| 主机及卡 | RK3588 + BM1684X；物理卡 1 对应软件 device 1，PCIe 3.0 ×1 |
| 视频 | Big Buck Bunny 动画，1920×1080、H.264、25 FPS、约 8 Mbps |
| 并发输入 | 32 个独立进程重复读取同一份本地视频，每路独立解码器和模型实例 |
| 模型 | YOLOv8s INT8，输入 640×640，batch 1 |
| 分析链路 | 硬件解码 → 设备内图像转换 → 预处理 → 推理 → 后处理 → 检测 JSON |
| 32 路测量时长 | 预热 180 秒，正式采集约 120 秒，窗口 60 秒 |

YOLOv8s 中的 s 表示 small，属于该系列的小型规格；batch 1 表示每批一张图，不是 1B 参数。INT8 指内部量化，本模型的输入输出张量为 float32。

动画用于验证链路和演示性能；32 路重复文件并非 32 个真实摄像头。实际素材的编码、码率和检测目标数量会影响性能，此素材不能用于评价客户业务识别精度。

## 实测结果一览

| 测试 | 总吞吐 | 每路或计算口径 | 说明 |
|---|---:|---|---|
| 32 路纯解码 | 815.21 FPS | 最低逐路窗口 23.26 FPS | 短测，不能理解为所有流始终稳定 25 FPS |
| 30 路纯解码，正式采集 15 分钟 | 749.96 FPS | 各路平均 24.989～25.010 FPS | 有一个统计窗口下降，最低逐路窗口 22.59 FPS |
| 原 BGR 路径，32 路解码＋推理 | 32.68 FPS | 平均每路 1.02 FPS | 优化前对照 |
| device-bgr，32 路解码＋推理 | **114.10 FPS** | **平均每路 3.57 FPS** | 各路平均 3.31～3.75，最低逐路窗口 3.06 FPS |
| 独立模型计算，batch 1 | 354.50 图/秒 | TPU 采样峰值 100% | 不包含完整视频链路 |
| 独立模型计算，batch 4 | 370.11 图/秒 | TPU 采样峰值 100% | 视频 worker 目前仍只支持 batch 1 |

纯解码、完整分析和独立模型计算采用不同处理路径，不能直接将吞吐差值全部归因于 TPU。32 路优化测试正常完成，检测记录完整，退出码全部为 0；34,006 条检测列表与原路径对应源帧一致。各路重复使用同一素材，这些记录不是 34,006 个不同场景。

每路 3.57 FPS 表示平均每秒完成约 3～4 张画面分析，约 280 毫秒一张。当前每帧分析、不抽帧，因此本地读取和处理会落后源视频进度；它不等于实时抽取最新画面分析，也不代表 280 毫秒端到端时延。32 路本轮最大计划落后约 257.85 秒。

抽帧可以减少推理请求，但本阶段仅讨论、未实现或验证。每路 2 / 3 FPS 对应 32 路共 64 / 96 次分析每秒，这只是需求计算，不能写成已实测结果。

## 演示操作

在设备工程根目录执行，同一张卡上的测试依次运行。演示可直接打开现有报告；需要复测时使用下面命令。

```bash
# 32 路解码＋推理，约 5 分钟后生成完整报告
bash scripts/run_single_card_analysis_auto.sh --device 1 --steps 32 \
  --measure-only --image-path device-bgr \
  --warmup 180 --duration 120 --window 60 --stall-timeout 180
```

控制台会打印唯一 Results 目录。在另一终端进入该目录后执行 `watch -n 5 cat report.md`。报告在开始、每档结束和最终收尾时更新，不是逐秒刷新当前档的最终 FPS。查看资源可另开终端运行 `bm-smi`；本演示通过报告和检测记录展示分析过程，不包含实时画框视频。

```bash
# 纯解码对照：应在分析测试结束后执行
bash scripts/run_single_card_decode_auto.sh --device 1 --steps 32 \
  --measure-only --warmup 60 --duration 120 --window 60

# 独立模型计算：应在同卡视频测试结束后执行
python3 scripts/run_single_card_tpu_bench.py --device 1 --calculate-times 5000
```
