# PCIe ×2 与输出读取对照

## 测试条件

RK3588 + BM1684X，BDF `0001:11:00.0`。18:23 后系统只枚举到一张算能设备，其软件编号为 device 0；此前 ×1 / 双卡配置中同一 BDF 为 device 1。设备端和根端口当前链路均为 8 GT/s、×2，测试前后保存原始枚举快照。`LnkCap` 是端口能力，`LnkSta` 是实际协商状态；模组端支持更宽链路时，×2 后面的 downgraded 不能解释为仍在跑 ×1。

YOLOv8s INT8 batch 1，模型 SHA256 `b09b7c5bc0a8c18c67f839c33551ba35fa37748d10eafb6a8f9d41ee87f086b4`，输入 640×640，输出 FP32 `[1,8400,84]`，每帧 2,822,400 字节。完整视频测试使用相同 BBB 1080p25 H.264 素材、device-bgr 路径，不抽帧、不画框、不编码，输出仍由主机筛选和 NMS。

基线视频 worker SHA256 `dc61e94145883dc2b335bfec53cca344c164f17fb5cfe005419136666db91037` 未变。×1 与 ×2 是不同时间和枚举配置下的对照，不是只改一个寄存器的同时实验。本文不会将所有差异归因于链路宽度。

## 带宽

[官方 CDMA 工具原始记录与 CSV](../benchmarks/20260907/20260907_182533/report.md)。每个尺寸重复 3 次，每次每方向 10 次调用，9 轮数据核对均成功。SDK profile 的 CDMA 耗时与应用侧调用耗时分别报告；它们都不等于 PCIe 理论上限。

读取一帧输出大小的数据时，CDMA profile 约 1.37～1.40 GB/s，应用侧读取约 334～346 MB/s。同一数据量下，两层计时有明显差距。原工具虽标 MB/s，源码使用 `1024×1024` 为分母，本仓库报告已明确原始 MiB/s 并换算十进制 MB/s。

官方源码的 PCIe 常规读取路径包含驱动中转缓冲和 `copy_to_user`，可作为后续定位方向；本轮没有将运行中驱动的这些子阶段分别计时，不能把全部差值直接算作 CPU 复制或 PCIe 等待。[BMLib 读取实现](https://github.com/sophgo/libsophon/blob/main/bmlib/src/bmlib_memory.cpp)、[驱动实现](https://github.com/sophgo/libsophon/blob/main/driver/bm_memcpy.c)、[官方带宽工具](https://github.com/sophgo/libsophon/blob/main/bmlib/tools/test_cdma_perf.cpp)。这些上游源码用于机制参考，未验证与板端驱动的逐行一致性。

## 模型与回传隔离对照

[×2 原始诊断](../benchmarks/20260907/20260907_182538_371823/stages.csv)，对照此前同模型 [×1 诊断](../benchmarks/20260907/20260907_170854_649512/stages.csv)。每组预热 3 秒、采集 10 秒，常驻零输入，非视频分析 FPS。

| 模式/进程数 | ×1 循环/秒 | ×2 循环/秒 |
| --- | ---: | ---: |
| 纯计算 / 4 | 372.29 | 373.29 |
| 纯回传 / 4 | 224.59 | 394.16 |
| 计算并回传 / 4 | 187.40 | 251.06 |
| 计算并回传 / 8 | 140.88 | 198.74 |

4 进程纯回传有效带宽从约 634 MB/s 提高到 1,112 MB/s；继续增加到 8 进程后 ×2 回传降至约 593 MB/s，不能靠增加进程数线性扩展吞吐。模型纯计算上限本轮仍在约 373 次/秒，代表当前交付模型和测试方式，不能外推为所有模型的能力。

## 复测命令

先确认 `bm-smi` 的编号与 BDF，再确认 `lspci` 或 sysfs 中的实际宽度。同卡任务依次执行：

```bash
python3 scripts/run_pcie_bandwidth.py --device 0
python3 scripts/run_inference_diagnostics.py --device 0 --steps 1,2,4,8
bash scripts/run_single_card_analysis_auto.sh --device 0 --model-preset yolov8s \
  --steps 1,4,8,12,16,20 --warmup 30 --duration 60 --window 30 --stall-timeout 180
```

主机 CPU 亲和性和输出读取分块是额外实验变量，详见[诊断操作](inference-diagnostics.md#pcie-带宽与读取分块)。任何变体必须核对输出内容，不能用少读输出字节或降低检测阈值口径制造吞吐提升。
