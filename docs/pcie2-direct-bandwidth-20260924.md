# 无飞线PCIe2 x1带宽测试（2026-09-24）

> 阅读顺序：6。主要目的：记录新无飞线板的PCIe2纯DMA带宽，不涉及预览业务。 [返回阅读导航](pcie-reading-guide.md)。

本矩阵最高单向两轮均值：上传343.93MB/s、下载348.13MB/s，均为16MiB块、4线程；约为500MB/s理论单向带宽的68.8%和69.6%，不是实测线速利用率。1MiB块同时双向、每方向1线程时，上传205.26MB/s、下载158.33MB/s；双向不能同时维持各自单向最高值，说明全双工接口不保证本SDK路径端到端互不影响，尚未定位限制所在。

本轮仅测DMA上传、下载和双向传输，没有视频墙、解码、推理或VPP负载。设备为新无飞线板上的device0，BDF 0004:41:00.0，实测5GT/s x1；各档前及结束后核对启动标识和链路。SDK 0.5.1用户态库在独立目录解包使用，未安装或替换现有驱动。探针沿用dma_vpp_probe.cpp，在新板重新编译；二进制哈希与旧板不同，因此属于新平台复测，不能把全部差异归因于飞线。

每档2秒预热、8秒正式，14种配置正反两轮，共28档，全部完成且数据校验通过。正式窗口只统计完整落在窗口内的调用，分配、初始化及输出校验不计入带宽。普通主机vector缓冲、每线程独立设备内存和handle。MB/s采用十进制。

上传=主控到卡，下载=卡到主控；单向行在独立测试中测得，双向行才是同时传输。每方向线程数不是所有方向合计。短测最高值不等于物理线速满载或长期保证值。
