# PCIe3 x1：24路不限频视频墙一小时结果

[返回阅读导航](pcie-reading-guide.md)。目的：检验24路分析、结果回传和同步预览同时开启、取消主动限频后的1小时连续性。

正式测量3600秒，另加30秒预热；程序和监督正常退出，24路均完成且无源结束，记账完整。输入是原1080p24素材无重编码拼接至3700秒；device2、0003:31:00.0、8GT/s x1。gate64reuse开启，infer-fps=0、preview-fps=-1、wall-fps=0，播放器时基60FPS。整墙刷新包含重复画面，不等于各路有效预览。

## 校验及限制

取回38个普通文件并逐一SHA256校验一致，跳过1个FIFO。原始数据位于data/results/wall24-pcie3-1h-20260924-120313，analysis.json为汇总，verification.json为哈希清单。
正式窗口内遥测3596条，状态快照720条。快照覆盖3596.67秒，推理增量284.693FPS、预览增量每路11.862FPS，与summary交叉核对；整墙发布约47.51FPS。所有快照有图=True，相邻快照未增长通道次数=0。采样解码源滞后最大35.89ms，不是全量事件最大值。

本配置完成了一次1小时运行，分析连续性由逐事件统计支持；软件has_image与帧号增长确认提交，不等同目视HDMI或逐显示帧验收。没有记录独立预览相邻完成最大间隔，不将分析空窗等同屏幕停顿。

此前PCIe2的约270FPS、每路11.28预览FPS仅为另一张卡约20秒样本，不是等时长一小时对照。不能用本次结果把差异全部归因于接口，亦不能推导32路或独立RTSP摄像头的长稳结论。
